# Project Name

A modern web application built with **Vite**, **React**, and **TypeScript**.

---

## 🚀 Tech Stack
- [Vite](https://vitejs.dev/) – Fast build tool and dev server
- [React](https://react.dev/) – Framework
- [TypeScript](https://www.typescriptlang.org/) – Type safety
- [TailwindCSS](https://tailwindcss.com/) – Utility-first CSS
- [Shadcn UI](https://tailwindcss.com/) – Modern UI Component Library
- [Zustand](https://tailwindcss.com/) – Lightweight state management tool
- [ESLint](https://eslint.org/) + [Prettier](https://prettier.io/) – Code quality & formatting

---
